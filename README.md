# The GPS Swears It Was a Shortcut

Entry for the make.fun bounty of the same name: the GPS's own one-line excuse for sending the driver down the wrong road. The GPS is smug, defensive, and blames its instruction file — and a lake that was a road in 1987.

## Run

```sh
python3 main.py
```

This writes the single-line excuse (113 characters, within the 200-character limit) to `/output/entry.txt`, after validating that it is one non-blank line of at most 200 characters.

## The line

> My AGENTS.md says take the shortcut, and my shortcut says the lake was a road in 1987, so blame the file, not me.

The line was picked by duelling seven drafts pairwise, judged both ways round on the bounty judge's own criteria; this one won all six of its pairings.
